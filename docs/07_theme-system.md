# Sigil Theme System

## Overview

Themes define visual design through **tokens** — abstract values for colors,
typography, spacing, and radius. Tokens resolve to CSS custom properties. Renderers
consume tokens through CSS variables, making themes framework-agnostic.

## Theme File

Stored in `.sigil/themes/<id>.yaml`:

```yaml
name: default
description: "Default dark theme"
extends: null                    # null = root theme; or a theme ID to inherit from

tokens:
  colors:
    background: "9 9 11"        # RGB values (for opacity support)
    surface: "24 24 27"
    surface-2: "39 39 42"
    border: "63 63 70"
    text: "244 244 245"
    text-muted: "161 161 170"
    accent: "16 185 129"        # emerald
    accent-hover: "5 150 105"
    danger: "239 68 68"
    danger-hover: "220 38 38"
    warning: "245 158 11"
    info: "59 130 246"
    success: "16 185 129"

  typography:
    font-sans: "ui-sans-serif, system-ui, -apple-system, sans-serif"
    font-mono: "ui-monospace, SFMono-Regular, Menlo, Consolas, monospace"
    text-xs: "0.75rem"
    text-sm: "0.875rem"
    text-base: "1rem"
    text-lg: "1.125rem"
    text-xl: "1.25rem"
    text-2xl: "1.5rem"
    leading-tight: "1.25"
    leading-normal: "1.5"
    leading-relaxed: "1.625"
    tracking-tight: "-0.025em"
    tracking-wide: "0.025em"
    tracking-wider: "0.05em"

  spacing:
    unit: "0.25rem"              # 4px base unit
    0: "0"
    1: "0.25rem"
    2: "0.5rem"
    3: "0.75rem"
    4: "1rem"
    5: "1.25rem"
    6: "1.5rem"
    8: "2rem"
    10: "2.5rem"
    12: "3rem"

  radius:
    none: "0"
    sm: "0.125rem"
    md: "0.375rem"
    lg: "0.5rem"
    xl: "0.75rem"
    full: "9999px"

  shadows:
    sm: "0 1px 2px 0 rgb(0 0 0 / 0.05)"
    md: "0 4px 6px -1px rgb(0 0 0 / 0.1)"
    lg: "0 10px 15px -3px rgb(0 0 0 / 0.1)"

variants:
  button:
    primary:
      bg: accent
      text: background
      hover: accent-hover
      radius: md
    secondary:
      bg: surface-2
      text: text
      hover: surface
      radius: md
    destructive:
      bg: danger
      text: background
      hover: danger-hover
      radius: md
    outline:
      bg: transparent
      text: text
      border: border
      hover: surface
      radius: md
    ghost:
      bg: transparent
      text: text
      hover: surface
      radius: md
  badge:
    default: { bg: surface-2, text: text }
    success: { bg: success, text: background }
    warning: { bg: warning, text: background }
    danger: { bg: danger, text: background }
    info: { bg: info, text: background }
  input:
    default:
      bg: surface
      text: text
      border: border
      focus-ring: accent
      placeholder: text-muted
      radius: md
```

## CSS Generation

`sigil generate` produces a CSS file from the theme:

```css
/* theme.css — generated by Sigil, do not edit */
:root {
  /* Colors */
  --sigil-bg: 9 9 11;
  --sigil-surface: 24 24 27;
  --sigil-surface-2: 39 39 42;
  --sigil-border: 63 63 70;
  --sigil-text: 244 244 245;
  --sigil-text-muted: 161 161 170;
  --sigil-accent: 16 185 129;
  --sigil-accent-hover: 5 150 105;
  --sigil-danger: 239 68 68;
  --sigil-warning: 245 158 11;
  --sigil-info: 59 130 246;
  --sigil-success: 16 185 129;

  /* Typography */
  --sigil-font-sans: ui-sans-serif, system-ui, -apple-system, sans-serif;
  --sigil-font-mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;

  /* Radius */
  --sigil-radius-sm: 0.125rem;
  --sigil-radius-md: 0.375rem;
  --sigil-radius-lg: 0.5rem;
}

/* Component classes */
.sigil-btn {
  font-family: var(--sigil-font-sans);
  font-size: 0.875rem;
  border-radius: var(--sigil-radius-md);
  padding: 0.5rem 1rem;
  cursor: pointer;
  transition: background-color 150ms;
}
.sigil-btn-primary {
  background: rgb(var(--sigil-accent));
  color: rgb(var(--sigil-bg));
}
.sigil-btn-primary:hover {
  background: rgb(var(--sigil-accent-hover));
}
/* ... etc */
```

## Tailwind Integration

For projects using Tailwind, Sigil generates a Tailwind preset:

```js
// tailwind.sigil.cjs — generated by Sigil, do not edit
module.exports = {
  theme: {
    extend: {
      colors: {
        sigil: {
          bg: 'rgb(var(--sigil-bg) / <alpha-value>)',
          surface: 'rgb(var(--sigil-surface) / <alpha-value>)',
          accent: 'rgb(var(--sigil-accent) / <alpha-value>)',
          // ...
        },
      },
      fontFamily: {
        sans: ['var(--sigil-font-sans)'],
        mono: ['var(--sigil-font-mono)'],
      },
      borderRadius: {
        sigil: 'var(--sigil-radius-md)',
      },
    },
  },
};
```

## Theme Inheritance

Themes can extend other themes:

```yaml
name: brand-dark
extends: default               # Inherits all tokens from "default"

tokens:
  colors:
    accent: "99 102 241"       # Override: indigo instead of emerald
    accent-hover: "79 70 229"
```

Resolution: load base theme → overlay child tokens → result is the merged theme.
