# Sigil Renderer Contract

## Overview

A renderer transforms a parsed, validated Sigil config into framework-specific source
files. Each renderer implements the `Renderer` interface and produces self-contained
output that can be compiled/built independently.

## Renderer Interface (Go)

```go
package renderer

// Renderer generates framework-specific code from Sigil configs.
type Renderer interface {
    // Name returns the renderer identifier (e.g., "go-templ").
    Name() string

    // Render generates code for a single page config.
    // ctx contains the resolved config, theme, datasources, and component schemas.
    // Returns a list of files to write.
    Render(ctx *RenderContext) ([]OutputFile, error)

    // RenderTheme generates theme-specific files (CSS, config).
    RenderTheme(theme *config.Theme) ([]OutputFile, error)

    // RenderDataSourceStubs generates handler stubs for datasources.
    RenderDataSourceStubs(ds *config.DataSource) ([]OutputFile, error)

    // SharedComponents returns shared/reusable component files that are generated
    // once and imported by all pages.
    SharedComponents(registry *components.Registry) ([]OutputFile, error)
}

// RenderContext provides everything a renderer needs to generate code.
type RenderContext struct {
    Page       *config.Page                  // Parsed page config
    Theme      *config.Theme                 // Resolved theme with tokens
    DataSources map[string]*config.DataSource // DataSource manifests by alias
    Registry   *components.Registry          // Component type registry
    ProjectConfig *config.ProjectConfig      // Project-level settings
}

// OutputFile represents a file to be written to disk.
type OutputFile struct {
    Path    string // Relative to output directory
    Content []byte // File content
    Mode    os.FileMode // File permissions (default: 0644)
}
```

## Go/Templ Renderer (Priority 1)

### What It Generates

| Input | Output | Example |
|---|---|---|
| Page config | `.templ` file | `pages/sprint_dashboard.templ` |
| Component usage | Shared component `.templ` files | `components/data_table.templ` |
| Theme | CSS file with custom properties | `theme.css` |
| DataSource | Go handler stub | `handlers/sprint_handler.go` |
| Layout | Page layout template | `layouts/page_layout.templ` |

### Generated Templ Component Example

Input config:
```yaml
- id: btn-new-sprint
  type: button
  props:
    label: New Sprint
    variant: primary
    icon: plus
  actions:
    click:
      type: modal
      title: "Create Sprint"
```

Generated Templ:
```go
// btn-new-sprint
templ ButtonNewSprint() {
    <button
        class="sigil-btn sigil-btn-primary"
        hx-get="/ui/modals/create-sprint"
        hx-target="#modal-container"
        hx-swap="innerHTML"
    >
        @IconPlus("w-4 h-4")
        <span>New Sprint</span>
    </button>
}
```

### HTMX Integration

Actions map to HTMX attributes:

| Action type | HTMX attribute |
|---|---|
| `navigate` | `hx-get` with `hx-push-url` |
| `modal` | `hx-get` (loads modal content) with `hx-target="#modal-container"` |
| `http POST` | `hx-post` with `hx-vals` |
| `http DELETE` | `hx-delete` with `hx-confirm` |
| `emit` | `hx-trigger` custom event |
| `refresh` | `hx-get` on target component with `hx-trigger="refreshed from:body"` |
